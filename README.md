# VoyaGo

VoyaGo is a travel price comparison platform designed to help travellers compare flights, trains, hotels and cabs from a single interface.

The platform focuses on simplifying travel planning by allowing users to search, compare estimated prices, save travel options and manage trips through a unified interface.

## Features

### User Features

- User registration
- User login
- User logout
- User dashboard
- Flight comparison
- Train comparison
- Hotel comparison
- Cab comparison
- Travel date selection
- From and To location selection
- Swap From and To locations
- Airline filtering
- Stops filtering
- Maximum price filtering
- Sorting options
- Price comparison
- Price breakdown
- Cheapest option identification
- Fastest option identification
- Best-value option identification
- Wishlist
- Saved travel options
- My Trips
- User profile
- Price alerts
- Travel alerts
- Travel delay simulation
- Automatic itinerary adjustment
- Light and dark theme

## Travel Comparison

VoyaGo provides comparison interfaces for four major travel categories:

- Flights
- Trains
- Hotels
- Cabs

Users can enter their travel requirements and compare available options through a single interface.

## Flight Comparison

Flight results display information such as:

- Airline
- Flight number
- Departure time
- Arrival time
- Duration
- Stops
- Travel date
- Estimated price

Users can compare flight options and continue to the price comparison page.

## Train Comparison

Train comparison includes:

- Train information
- Departure
- Arrival
- Duration
- Stops
- Class information
- Estimated price

## Hotel Comparison

Hotel comparison includes:

- Hotel name
- Location
- Rating
- Amenities
- Room information
- Stay information
- Estimated price

## Cab Comparison

Cab comparison includes:

- Provider
- Vehicle information
- Estimated arrival
- Estimated fare
- Travel information

## Price Comparison

The price comparison page allows users to compare the same travel option across multiple platforms.

It displays:

- Platform name
- Estimated total price
- Price breakdown
- Cheapest option
- Best-value option
- Fastest option
- Potential savings
